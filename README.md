# 实验室信息管理系统（LIMS）

一套面向检测中心的实验室委托试验管理系统，覆盖「委托申请 → 审核 → 样品 → 排期 → 实验 → 报告」完整闭环。

技术栈：**FastAPI（Python）+ SQLite + Vue3（前端内置，无需构建）**，单机/内网可直接运行。

## 快速启动

**方式一：双击运行（推荐）**

双击 `run.bat`（或右键 `run.ps1` → 使用 PowerShell 运行），首次会自动创建虚拟环境并安装依赖，然后启动服务。

启动后在浏览器打开：<http://127.0.0.1:8000>

**方式二：命令行**

```bash
cd lims
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## 功能模块

- **工作台**：统计看板 + 待审核委托 + 待做实验
- **委托申请**：中英双语字段，无需登录，自动生成委托单编号
- **委托查询**：委托人凭编号+电话查询；登录用户可按状态/关键字检索
- **委托审核**：通过（自动分配实验编号、生成样品、录入费用明细）/ 否决
- **样品管理**：接收、打印条码、退还/报废/留存、操作明细
- **实验排期**：选样品+设备，按实验用时+过渡用时生成排期计划
- **开始/结束实验**：记录实际起止时间，逐样品填 OK/NG，全部排期完成方可结束
- **实验报告**：实验委托记录单（表-TC05-01A）、检测报告（表-TC11-02A），浏览器打印即导出 PDF
- **设备管理**：设备台账、分类（功率/环境/其它）、计价参数、停用/报废
- **设备计价**：金额 =（开机费 +（电费/小时 + 折旧费/小时）× 次数）× 数量 × 折扣
- **设备校准维保**：每台设备维护校准/维修/保养记录，校准自动更新设备有效期，工作台「设备到期提醒」提前预警
- **客户档案**：委托单位（客户）建档，登记联系人/电话/邮箱/地址；委托申请时输入单位名称自动带出联系人与电话，并可查看该客户历史委托
- **报告留档与签发**：委托记录单 / 检测报告（常规、检测版）一键签发归档，自动生成报告编号 `BG{YYMM}-四位`，归档列表支持查看、打印、作废
- **统计图表看板**：委托趋势、各项目费用、设备使用时长、实验员工作量、结果 OK/NG 分布等（自绘 SVG，离线可用）
- **审计日志**：关键操作（登录、委托增删改、审核、样品、排期、实验、设备、报告签发、客户等）全程留痕，支持按操作/操作人/关键字筛选与分页
- **通知中心**：新委托待审核、审核通过/否决、实验完成、报告签发等自动推送，顶栏铃铛实时提示未读
- **修改密码**：登录用户在顶栏自行修改密码
- **数据导出**：委托单列表一键导出 CSV（含状态/关键字筛选）
- **展板**：待试验展板、设备使用明细、设备排期展板
- **交接班**：日夜班交接记录

## 编号规则

- 委托单编号：`YYMM-四位流水`（如 `2312-3898`）
- 实验编号：`YYMM-三位流水`（审核通过后分配，如 `2401-002`）
- 样品编号：`实验编号-两位流水`（如 `2401-001-01`）
- 报告编号：`BG{YYMM}-四位流水`（签发归档时生成，如 `BG2401-0001`）

## 目录结构

```
lims/
├── app/
│   ├── main.py          # FastAPI 入口
│   ├── config.py        # 配置（数据库、密钥）
│   ├── database.py      # 数据库连接
│   ├── models.py        # ORM 模型
│   ├── schemas.py       # 请求/响应模型
│   ├── security.py      # 密码哈希 + JWT
│   ├── numbering.py     # 编号生成
│   ├── audit.py         # 审计日志辅助
│   ├── notify.py        # 通知推送辅助
│   ├── seed.py          # 建表 + 种子数据
│   ├── serializers.py   # 对象序列化
│   └── routers/         # 各业务模块路由（含 statistics/audit/notifications/customers/export）
├── static/              # 前端（Vue3 已内置，无需联网，charts.js 为自绘 SVG 图表）
├── requirements.txt
├── run.bat / run.ps1    # 启动脚本
└── lims.db              # SQLite 数据库（运行后生成）
```

## 说明

- 数据库为单文件 `lims.db`，备份只需复制该文件。
- 生产/正式环境建议：将 `config.py` 中的 `SECRET_KEY` 通过环境变量 `LIMS_SECRET_KEY` 覆盖，并可将 `DATABASE_URL` 切换为 PostgreSQL。
- 报告通过浏览器「打印 → 另存为 PDF」导出。
